Offline model benchmark

A plain logistic regression is fitted to the same structured features the deterministic rules use, then validated leave-one-child-out. It produces no alert, score or individual prediction. This page exists so the report can quote a measured figure instead of asserting that a model "works".

This model is not connected to any child's care. Production decisions remain deterministic rules plus a named human. The benchmark labels are the synthetic cohort's current state, not a forecast.

A false positive here is a stable synthetic period classified as difficult. In this benchmark it costs a review, not a child's reputation, because no output reaches a child.

How to read the figures

  • Precision falls when the model flags stable periods; recall falls when it misses difficult ones. They trade off at the fixed 0.5 threshold.
  • ROC AUC is threshold-free ranking quality. Accuracy alone hides class imbalance, so it is reported beside prevalence.
  • The Brier score is the mean squared probability error; lower is better and it rewards calibrated probabilities, not only labels.
  • Ground truth is synthetic. These figures measure the method against the generator's labels, not clinical outcomes.

Weights are from a separate fit on the whole synthetic cohort and are not part of the validated result. They answer "which features move the score?" not "does this model work?" or "what causes difficulty". Features are standardised, so a weight is a change in log-odds per standard deviation. Scores move together, so individual signs are unstable under collinearity and should not be read as causal directions. No free text, note or message is a feature.
